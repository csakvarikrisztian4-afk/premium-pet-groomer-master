# Deployment

## Cloudflare Pages

1. Connect the GitHub repository.
2. Select the production branch (`main` only after review).
3. Framework preset: none.
4. Build command: leave empty.
5. Build output directory: `/`.
6. Deploy and test the generated Pages URL.
7. Connect the client domain only after approval.

## Branch previews

Use Cloudflare Pages preview deployments for `premium-redesign` and future feature branches. Never merge a visual change to `main` before checking both mobile and desktop previews.
